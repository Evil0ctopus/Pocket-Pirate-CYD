# Pocket Pirate CYD

A pirate-themed handheld "life" firmware for the Hosyond ESP32-S3 2.8" touch
module (the **cheap black display**). You pick a captain, and that pirate lives
in an animated 2.5D ocean world that levels up and visually evolves as you use
the device's tools.

It is a **defensive / passive** network-survey handheld — the same shape as
PorkChop-style firmware, but built around **detection and auditing** instead of
RF attacks. See [Scope & ethics](#scope--ethics).

## Hardware profile

- ESP32-S3R8, 16 MB flash, 8 MB OPI PSRAM
- 240x320 ILI9341 TFT over SPI (LovyanGFX)
- FT6336G capacitive touch over I2C
- MicroSD (4-bit SDMMC), RGB status LED, battery ADC, I2S audio pins

Pin map: [`include/board_pins.h`](include/board_pins.h).

## The world

- **Captain select** on first boot (roster in `main.cpp`).
- Animated sea/ship/pirate scene with a header showing level, XP and doubloons.
- **Level 0 -> 10 evolution:** the avatar gains a coat, belt, tricorn, eyepatch,
  telescope, parrot and medal across tiers; the ship grows from raft to galleon.
- **Loot & XP:** Chart Fragments (Wi-Fi APs), Message Bottles (BLE devices),
  Cargo (SD logs) and Doubloons. Progress persists in NVS.
- Tap **STATIONS** to open the tool grid.

## Illustrated art pack (optional)

By default the world is drawn with the built-in vector renderer. For a modern
illustrated, animated look, drop an **art pack** on the SD card's `/art/` folder
and the firmware decodes and animates PNG assets on-device instead — parallax
sky/clouds/waves, a bobbing ship, and sprite-sheet captain animations (looping
idle + tap-to-wave). Anything missing falls back to the vector renderer, so a
partial pack is fine.

Generate the art (AI image generator or an artist), pack it, and copy it over:

```
python tools/build_artpack.py artpack_src artpack_out   # needs: pip install pillow
# then copy artpack_out/* to the card's /art/ folder and reboot
```

The project's committed look is **Bjorn-style color pixel art**, generated by
`tools/make_pixel_pack.py` (native-res authoring, limited palette, dark outline,
NEAREST upscale — never smoothed):

```
python tools/make_pixel_pack.py                              # writes artpack_pixel_src/
python tools/build_artpack.py artpack_pixel_src artpack_pixel
# copy artpack_pixel/* to the card's /art/ folder and reboot
```

Preview any packed folder on your PC (no SD card needed) — it composites the
scene exactly as the firmware draws it, so it also checks your layer geometry:

```
python tools/preview_world.py artpack_pixel       # animated scene -> preview.gif + .png
python tools/preview_ships.py artpack_pixel        # raft->galleon sheet -> ships_check.png
python tools/preview_captain.py artpack_pixel --avatar 0  # tier 0->4 -> captain0_tiers.png
python tools/preview_captain.py artpack_pixel --roster    # all 4 captains -> roster_tiers.png
```

Full spec, layer/naming reference, and a ready-to-use prompt pack:
[`docs/ART_PACK.md`](docs/ART_PACK.md).

## Stations (tools)

| Station          | What it does                                              |
|------------------|-----------------------------------------------------------|
| Crow's Nest      | Passive Wi-Fi survey: SSID/BSSID/RSSI/channel/enc + **vendor (OUI)** |
| Harbor Ledger    | Passive BLE device discovery + **vendor (OUI)**           |
| Chart Room       | **WiGLE 1.4** wardrive logger -> `/wigle.csv` on SD       |
| Lookout          | Channel-occupancy analyzer (from scan data)               |
| Spyglass         | Surveillance-camera spotter (Flock/ALPR) — *detection only* |
| Tracker Watch    | Nearby BLE item-tracker (AirTag/Tile/SmartTag) detector   |
| Rigging Watch    | Deauth/disassoc **attack detector** (defensive IDS)       |
| Hull Inspection  | Security-posture audit of nearby networks                 |
| Captain's Log    | microSD file browser (read-only)                          |
| Ship's Systems   | Diagnostics: chip, heap, PSRAM, flash, uptime, battery    |
| Signal Lantern   | RGB LED effects (+ sound preference)                      |
| Probe Watch      | Passive **probe-request** client sniffer (SSID + vendor)  |
| Deep BLE ID      | Decodes BLE ads: company, iBeacon, Eddystone, Continuity  |
| Instruments      | Onboard sensors: core temp, battery                       |
| Settings Cabin   | Brightness, sound, reset progress                         |

The grid paginates (9 per page) — tap the page arrows in the bottom bar. New
station work goes in `src/tools.cpp`; register it in the `kTools[]` table.

Vendor identification uses a hand-curated subset of the IEEE OUI registry in
[`include/oui.h`](include/oui.h) (randomized/locally-administered MACs report as
`random`, which is expected). BLE company IDs are decoded from a subset of the
Bluetooth SIG registry. Neither list is exhaustive — extend from the official
sources as needed.

## Scope & ethics

This firmware intentionally **does not** include Wi-Fi attack modules —
deauthentication, beacon/probe spam, evil-portal credential capture, or
EAPOL/PMKID handshake capture. Those are RF denial-of-service or credential-
capture tools that affect every device in range, not just your own network.

Instead their slots are filled with the **defensive inverse**: Rigging Watch
detects deauth attacks, and Hull Inspection audits your own network's posture.
All collection is limited to **passively-observable, publicly-broadcast
metadata** — beacons, BLE advertisements and probe requests. Probe Watch and the
WiGLE logger observe only what devices openly transmit; nothing associates,
injects, or captures private/credential data.

**Spyglass signatures:** `include/spyglass_signatures.h` ships with placeholders.
Populate it with verified camera signatures (e.g. from the DeFlock project)
before relying on detection.

## Build & flash

1. Open in VS Code + PlatformIO.
2. `pio run -e cheap-black-display` to build.
3. Put the board in download mode (hold BOOT, tap RESET) if no COM port appears,
   then `pio run -e cheap-black-display -t upload`.
4. Serial monitor at 115200 baud.

The `platform` resolves to the installed pioarduino Espressif32 (Arduino-ESP32
3.3.8), which provides the `esp32-s3-devkitc1-n16r8` board and the 3.x APIs
this firmware targets (pin-based LEDC, `rgbLedWrite`, current BLE scan API).
